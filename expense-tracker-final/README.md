# Expense Tracker

A small, self-contained expense tracker built with TypeScript, Vite, and React. Expenses are
saved only in browser local storage; the app has no backend or authentication.

## Setup

```bash
npm install
```

## Commands

```bash
npm run dev      # Start the development server
npm test         # Run Vitest unit tests
npm run lint     # Type-check with TypeScript
npm run build    # Create a production build
```
